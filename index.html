「かずのもり」プライバシーポリシー

制定日: 2026年11月13日

「かずのもり」(以下「本アプリ」)は、未就学のお子さま向けの学習アプリです。本アプリは、お子さまと保護者の皆さまのプライバシーを大切にしています。

1. 収集する情報

本アプリは、氏名、メールアドレス、位置情報、写真、連絡先、端末の識別子など、個人を特定できる情報を一切収集しません。

2. 端末内に保存する情報

ゲームの進み具合(各レベルで獲得した星の数)のみを、お使いの端末の中に保存します。この情報が端末の外へ送信されることはありません。アプリを削除すると、この情報も削除されます。

3. 第三者への提供・広告・解析

本アプリには、広告、アプリ内課金、外部サイトへのリンク、第三者の解析ツールやトラッキング機能は含まれていません。情報を第三者に提供することもありません。

4. 音声について

問題の読み上げには、iPadに標準で搭載されている音声合成機能を使用しています。マイクは使用しません。

5. お問い合わせ

本ポリシーおよび本アプリに関するお問い合わせは、以下のページからお寄せください。
https://github.com/Joy-Zhang-0303/kazunomori/issues

6. 改定

本ポリシーを変更する場合は、このページでお知らせします。

English summary: This app does not collect or share any personal information. It contains no ads, no in-app purchases, no external links, and no analytics or tracking. Only game progress (stars earned) is saved locally on the device and is never transmitted. Contact: GitHub Issues
